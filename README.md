# 虎扑阅读器

一个 VS Code 扩展：在资源管理器侧边栏浏览虎扑英雄联盟专区，以及豆瓣“今天谁又开麦了”小组的公开帖子。点击帖子后用只读 Markdown 虚拟文档阅读正文和公开评论。

## 运行

1. 用 VS Code **打开本文件夹**。
2. 在终端运行 npm install。
3. 按 F5，选择“运行虎扑阅读器”，启动扩展开发主机。
4. 在新窗口的资源管理器中找到“git history”（虎扑）或“今天谁又开麦了”（豆瓣），点击帖子即可在编辑器阅读。

侧边栏列表末尾的“加载更多帖子”会继续读取下一页；刷新按钮重新获取第一页。阅读帖子时，编辑器右上角的刷新按钮重新获取该帖。也可以从命令面板运行“虎扑阅读器：加载更多帖子”“虎扑阅读器：刷新当前帖子”和“虎扑阅读器：在浏览器中打开当前帖子”。

正文图片默认不自动加载；在编辑器里按住 Ctrl（macOS 按 Command）并点击“查看图片”链接即可打开图片。设置 hupuReader.cacheMinutes 可以调整内存缓存时长，默认 5 分钟，设为 0 则关闭缓存。

## 目前的范围

- 帖子列表来自虎扑公开的英雄联盟专区页面；正文和评论来自虎扑移动端公开页面。列表保持虎扑返回的顺序。
- 豆瓣小组使用 https://www.douban.com/group/748338/ 的公开列表与帖子页面，支持加载更多帖子及显示当前页公开评论。豆瓣登录、入组和受限内容尚不支持。
- 虎扑展示页面返回的亮评与首批普通评论，重复评论自动去重。评论分页、登录、回复和收藏尚未实现。
- 虚拟文档是只读的，缓存仅保存在当前 VS Code 会话内。
- 虎扑页面结构、访问限制和网络状态可能变化。遇到验证页、网络错误或不支持的嵌入内容时，扩展会显示提示，可用命令打开原帖。
- 请求由扩展进程直接发出；某些环境中的 VS Code 代理设置可能不会自动应用到 Node.js 请求。

## 豆瓣要求验证或登录时

豆瓣有时会将扩展的匿名请求跳转到安全验证页面。扩展不能自动使用浏览器的登录状态，也不会自动读取浏览器 Cookie。

1. 在豆瓣板块点击“豆瓣需要验证或登录 · 点击打开小组”，在浏览器中完成验证；如果小组需要登录或入组，请先用有权限的账号完成登录和入组。
2. 在浏览器按 F12 打开开发者工具，选择 Network（网络），刷新小组页面，点击域名为 www.douban.com 的小组页面请求，在 Request Headers（请求标头）中找到 Cookie，复制它的值。
3. 回到 VS Code，点击板块里的“验证后设置豆瓣浏览器会话”，在密码式输入框中粘贴该值。也可从命令面板运行“豆瓣阅读器：设置已验证的浏览器会话”。
4. 设置后扩展会刷新小组。会话过期或豆瓣再次要求验证时，需要重复以上步骤。

Cookie 只保存在 VS Code 的安全存储中，扩展只会将它发送给 www.douban.com；不要把 Cookie 发到聊天、文档或其他人。可通过命令面板运行“豆瓣阅读器：清除浏览器会话”删除它。验证、登录或会话设置都不能授予原本没有的小组访问权限。

运行 npm test 可执行解析与缓存测试。扩展不保存账号密码，也不会提交任何内容；浏览器会话仅在你主动设置时保存。
